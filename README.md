### 👋 A little about me

I'm Ahmed, a backend developer who genuinely enjoys the part of the web most people never see. While others admire the buttons, I'm the one making sure that when you click them, something fast, secure, and reliable actually happens.

My journey started with a simple HTML page and a lot of curiosity. Somewhere between my first `<div>` and my first `php artisan migrate`, I fell in love with **Laravel**, and I've been building with it ever since.
